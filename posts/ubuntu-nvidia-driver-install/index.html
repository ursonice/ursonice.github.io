Ubuntu Nvidia Driver Install

작성 2023년 5월 17일수정 2025년 8월 16일

서론

우분투 20.04 환경에서 Nvidia driver 설치 방법에 대해서 설명한다.

목차

  1. Nvidia-driver 설치
  2. Driver 설치 확인

Nvidia-driver 설치

아래 명령어를 입력하면 다음과 같은 화면이 뜨는데 recommended 부분을 설치하면되는데 open버전이 아닌 걸로 설치하면 된다.

driver: nvidia-driver-530-open - distro non-free recommended 이렇게 되어있는데 이걸 설치하지말고 open이 빠진 driver: nvidia-driver-530 - distro non-free 를 설치하자.

참고: 470을 설치했을 때 CUDA ToolKit이 Ubuntu 20.04까지만 지원한다 (CUDA Version 11.X), 500번대 버전이 Ubuntu22.04를 지원하니 참고하자(CUDA Version 12.X)

$ ubuntu-drivers devices

수동 설치 명령어

$ sudo apt install nvidia-driver-530

설치가 완료되면 리부팅 해준다.

$ sudo reboot

Driver 설치 확인

아래 명령어를 입력했을 때 GPU가 잡히는지 확인한다.

$ nvidia-smi
